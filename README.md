# 모닝콜 (morning-alarm)

멀리 있어도 서로 아침을 깨워주는 가족 알람 앱. 누군가 알람을 예약하면 상대 폰에서 **무음이어도 알람 스트림 최대 볼륨**으로 보낸 사람이 쓴 문장을 TTS가 반복해 읽어준다. 역할 구분 없이 **서로** 보낼 수 있고, **여러 명**과 연결할 수 있다.

## 주요 기능

- **양방향 알람**: 연결된 누구에게나 알람 예약. 시간·요일 반복(매일/요일별), 울림 횟수(1~10회)·간격(1~30분) 설정
- **알람 거절 시간**: 취침·수업·미팅·운동·기타 사유로 요일+시간대를 무제한 등록. 그 시간에 오는 알람은 울리지 않고 보낸 쪽 기록에 "거절됨(사유)"으로 표시. 알람을 만들 때 상대 거절 시간과 겹치면 **즉시 경고** (긴급 메시지는 예외)
- **무음 뚫는 소리**: 알람 스트림(STREAM_ALARM) 사용 — 무음/진동 모드, 통화 중에도 스피커로 크게 울림
- **그만 울리기 질문**: 최대 10개 질문·정답 등록, 정답을 맞혀야 그날 알람 종료
- **울림/반응 기록**: 언제 울렸고(또는 거절됐고) 상대가 언제 껐는지 보낸 사람 화면에서 확인
- **양방향 메시지**: 카톡처럼 채팅 + 전달됨/읽음 표시
- **긴급 전면 팝업**: 빨간 전체 화면 + 진동 + 낭독으로 즉시 전달
- **테스트 기능**: 연락처별 테스트 알람/팝업 전송, 내 폰에서 미리 듣기
- **헬스체크**: 절전·권한·볼륨·방해금지 때문에 알람이 못 울릴 상태면 양쪽에 경고
- **표시 시간대**: 기본 한국시간, 해외에서는 현지 시간으로 전환 가능
- **하나의 앱, 로그인 없음**: 이름과 전화번호만 입력. 전화번호로 연결 요청 → 상대가 수락하면 서로 연락처가 됨

## 구조

- Kotlin + Jetpack Compose (minSdk 26)
- Firebase Firestore(실시간 동기화) + 익명 인증 — 무료 플랜으로 충분
- 알람은 받는 기기에 동기화 후 **로컬 AlarmManager(setAlarmClock)** 로 울림 → 그 순간 인터넷이 끊겨 있어도 동작
